Reusable Chat Widget - Customization API

Test all customization options for the embeddable chat widget

1. HTML Attributes

Configure the widget via HTML attributes. Changes will recreate the widget.

2. CSS Custom Properties

Style the widget from outside using CSS variables. Set these on the <reusable-chat> element.

These CSS custom properties allow external theming without modifying the widget's internal styles.
--rc-primary-color Primary color for buttons, links, and accents
--rc-secondary-color Secondary color for gradients
--rc-background-color Main background color
--rc-text-color Primary text color
--rc-border-color Border and divider color
--rc-font-family Font family
--rc-border-radius Border radius
--rc-shadow Box shadow

4. Custom Events

Listen to widget events for integration with your app.

Events are dispatched with bubbles: true and composed: true, so they cross the Shadow DOM boundary.
// Available events: const widget = document.querySelector('reusable-chat'); widget.addEventListener('rc-ready', () => { /* Widget initialized */ }); widget.addEventListener('rc-open', () => { /* Chat opened */ }); widget.addEventListener('rc-close', () => { /* Chat closed */ }); widget.addEventListener('rc-message', (e) => { /* e.detail: { message, conversationId } */ }); widget.addEventListener('rc-send', (e) => { /* e.detail: { message, conversationId } */ }); widget.addEventListener('rc-error', (e) => { /* e.detail: { error, code } */ });

5. Slots for Custom Content

Use named slots to inject custom content into the widget.

<!-- Example with custom header and footer --> <reusable-chat api-key="pk_xxx"> <!-- Custom header content --> <button slot="header" class="custom-header-btn"> <svg>...</svg> </button> <!-- Custom footer content --> <div slot="footer" class="custom-footer"> <a href="#">Privacy</a> | <a href="#">Terms</a> </div> </reusable-chat>

6. Inline Widget

Use <reusable-chat-inline> for an embedded chat view (not floating).

The inline widget renders directly in the page flow, perfect for dedicated chat pages or embedded messaging.
<reusable-chat-inline api-key="pk_your_key" user-id="user_123" user-name="John Doe" conversation-id="conv_abc" theme="light" ></reusable-chat-inline>
